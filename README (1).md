# Pecha Press

Paste Tibetan, get a pecha (དཔེ་ཆ): the long leaf, the double-ruled frame, the ༄༅ opening with the title in small type, folio words in the left margin, side numbers in the right, a blank leaf after each text. Downloads as a PDF — loose leaves, or three to a Letter/A4 sheet ready to print two-sided and cut.

A single static page (`index.html`), no build step. Fonts (Jomolhari, Noto Serif Tibetan, Noto Serif) load from Google Fonts.

Host anywhere that serves static files — e.g. Cloudflare Pages: connect this repo, framework preset **None**, build command empty, output directory `/`.
